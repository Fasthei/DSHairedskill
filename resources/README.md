# 可替换资源

按 [任务总览](../docs/implementation/ROADMAP.md) 的依赖顺序推进。每个子目录包含 README.md 和 TASKS.md，目前没有业务实现。

- [agent-presets](agent-presets/README.md)：维护本地 Agent、Swarm Lead/Worker 的可替换指引和结果要求。
- [method-notes](method-notes/README.md)：存放开发者编写的简洁方法资料和来源索引，按需提供给模型。
- [report-templates](report-templates/README.md)：提供基础 Markdown 报告布局，允许用户或模型替换。
